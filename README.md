# 可视清单 · 周视图任务日历

一个可以放在电脑上直接打开的桌面软件：**一次看一整周**，在日历上拖一下就能新建任务。

---

## 一、怎么打开

### 方式 A：下载免安装版（普通用户，推荐）

到本仓库的 **Releases** 下载 `可视清单-分享版.zip`，解压后双击 **`可视清单.exe`** 就能用。

首次打开是**完全空白的**，直接开始用就行。
软件自带运行环境（Electron），**不需要安装任何东西**，也不联网。
想放到桌面：双击包里的 **`创建桌面快捷方式.bat`**。

### 方式 B：从源码运行（开发者）

需要 Node.js 18+：

```bash
npm install
npm start
```

数据会写进项目目录下的 `data\`（已加入 `.gitignore`，不会被提交）。
跑自检：`npm test`。

### 自己打包免安装版

```bash
npm install
node dev\build-portable.js
```

产物在 `可视清单\` 文件夹里（exe + 运行环境 + 数据），整个文件夹拷给别人就能用。

---

## 二、怎么用

| 操作 | 效果 |
| --- | --- |
| 在空白处**按住拖动** | 拉出一段时间，松手即弹出「添加任务」，时间已填好 |
| 在空白处单击 | 不弹窗（避免误触）；想新建任务就拖动一段，或按 `N` |
| **按住 Shift** 再拖动 | 吸附精度临时切到 1 分钟（悬停看时间时也生效） |
| 拖动已有任务的**卡片中间** | 换时间、换日期（默认 5 分钟吸附） |
| 拖动任务**卡片底部** | 改时长 |
| 单击任务 | 打开编辑窗口（改标题/清单/时间/优先级） |
| 点任务窗口里的**「内容」** | 弹出记事本小窗写正文，可当备忘录；有内容的任务卡片上有小标记 |
| 任务右上角出现的小圆圈 | 打勾完成 |
| **右键**任务 / 清单 | 更多操作（复制到明天、删除、改颜色…） |
| **上下拖动**左侧的清单 | 调整清单顺序（松开即保存，可 `Ctrl+Z` 撤销） |
| 侧边栏「死亡线」右侧的 **+** | 添加高考 / deadline 这类很远的截止日，按天倒计时 |
| 顶部 `←` `→` | 上一周 / 下一周 |
| 顶部「周 / 日」 | 周视图、单日视图切换 |
| 单击日期表头 | 直接进入那一天 |
| 顶部**搜索框**输入关键词 | 弹出结果列表；`↑` `↓` 选择，`Enter` 或单击直接跳到任务所在的那一周 |

**吸附精度**默认 5 分钟（设置里可切 5 / 10 / 15 / 30 分钟），按住 `Shift` 拖动可精确到 1 分钟。

**「内容」就是任务的正文**，可以当备忘录用：纯文本、自动换行、`Ctrl+Enter` 保存关闭、`Esc` 关闭。
编辑已有任务时，关闭正文窗口即自动保存（可 `Ctrl+Z` 撤销）；新建任务时，点「确定」随任务一起保存。
有正文的任务，卡片右下角会有一个小圆点、全天任务条上会有一个小文档图标，鼠标悬停即可预览。

**新建任务的默认清单**：会记住你上一次用过（或改过）的清单；如果侧边栏正在筛选某个清单，就直接进那个清单。

**死亡线**：给「很远的截止日」用的一小块区域（高考倒计时、论文 deadline 这类），只显示剩余天数和标题，天数标红、越近越显眼，逾期显示负数。
点「死亡线」右侧的 **+** 新建（标题 + 截止日期）；点条目可编辑，编辑窗左下角有「删除」（也可以右键删除），都进了撤销栈（`Ctrl+Z`）。
当截止日落在当前显示的周里时，那一天在日历上的整列顶部会画一条深红色横线。

**搜索**：输入时会弹出结果面板，任务标题和「内容」正文都会搜（不区分大小写，已完成任务跟随「显示已完成」设置）。
排序是**逾期的排最前**（最近逾期的在前），其余按**离今天从近到远**；每条结果带清单色点和日期，点击或按 `Enter` 就跳到它所在的那一周。
`Esc` 清空并收起面板。

**时间轴范围是 08:00 – 22:00**，一周七天在这一屏里基本不用滚动就能看全。
早于 8 点或晚于 22 点的任务（比如在编辑窗里把时间改到 6:00）仍然保留，会贴在范围边缘显示，
卡片上下沿会出现虚线，卡片上的时间文字仍是真实时间 —— 拖动它就会回到可视范围内。

想改这个范围：编辑 `src/js/store.js` 里的 `dayStart` / `dayEnd`（单位是「从零点开始的分钟数」），
然后运行 `node dev\build-portable.js` 重新打包。

**快捷键**：`T` 回到今天 · `←/→` 翻页 · `N` 新建任务 · `/` 搜索 · `Ctrl+Z` 撤销 · `F12` 开发者工具 · `F5` 刷新

## 三、数据存在哪（更新不会丢）

从源码运行时数据在项目目录的 `data\`；绿色版则在 `可视清单\data\`，文件结构一样：

```
data\tasks.json              所有任务（纯文本，可随时备份）
data\tasks.backup.json       上一次保存前的自动备份
data\backups\tasks-日期.json 每天第一次打开自动快照（保留 30 份）
data\runtime\                Chromium 缓存，可以随便删
```

- **程序和数据分开放**：更新（重新打包、替换 `resources\app`）只覆盖程序文件，绝不会碰 `data` 文件夹。
- 任务的正文（「内容」）和标题存在同一个 `tasks.json` 里，导出、每日快照、恢复备份都会一起带上。
- **写到一半断电也不怕**：保存时先写临时文件、落盘后再原子替换，中途崩溃只会保留上一份完整数据。
- **坏数据进不来**：保存前会做结构校验，格式不对直接拒绝，不会把好数据覆盖成垃圾；万一文件真的损坏，打开时自动回退到备份，损坏文件改名留档不删除。
- **一键恢复**：设置 → 备份与恢复，可以选任意一份快照恢复（恢复前会自动再存一份当前数据）。
- 换电脑：把整个 `可视清单` 文件夹拷过去即可。
- 也可以在「设置」里导出 / 导入 JSON。
- 设置面板：右上角齿轮 —— 主题（浅色/深色）、每周起始日、时间刻度松紧、吸附精度、是否显示已完成、备份与恢复。

## 四、目录说明（想改代码看这里）

```
main.js / preload.js     Electron 主进程（窗口、数据读写）
src/index.html           界面结构
src/styles.css           全部样式（配色、圆角、深浅色主题）
src/js/util.js           日期 / 时间 / DOM 小工具
src/js/store.js          数据层：任务与清单的增删改查、撤销、持久化
src/js/calendar.js       日历渲染 + 拖拽交互（核心逻辑都在这）
src/js/dialogs.js        弹窗、右键菜单、确认框、设置面板、提示
src/js/app.js            启动、工具栏、侧边栏、快捷键
dev/make-icon.js         生成图标（纯 Node 手写 PNG/ICO，无依赖）
dev/build-portable.js    把代码打包进 可视清单\resources\app
dev/test-*.js            不启动界面就能跑的自检（npm test）
可视清单\                打包好的绿色版（构建产物，不入库）
```

改完代码后重新打包：

```powershell
node dev\build-portable.js
```

直接双击 `可视清单\可视清单.exe` 就能看到新效果。

## 五、常见问题

- **双击没反应**：看 `可视清单\data\error.log`（如果有），把内容发我。
- **窗口图标 / 任务栏图标是默认的**：exe 本身的图标改不了（没做资源替换），但窗口、任务栏、桌面快捷方式的图标都是本项目的蓝色图标。
- **全天任务在哪**：日期表头下面有一行「全天」，点那一行的空白处可以直接添加全天任务。
- **拖出来的时间段不对**：默认按 5 分钟吸附（设置里可切 5 / 10 / 15 / 30），按住 Shift 拖动可精确到 1 分钟。
